## AGENTS

**H2 :** Agents

Each agent has a role, a set of tools, and instructions you define. A Research Agent searches the web. An Analysis Agent reads the findings. A Writer Agent drafts the report.

**Example:**
> Research Agent — *"Find the top 5 competitor news items this week. Summarise each in 3 bullet points. Pass to Analysis Agent."*

*(Screenshot config agent)*

**Encart honnêteté :**
> Configuring an agent takes care — a clear role, precise instructions, the right tools. It's low-code, not no-code. Builders love it.

---

## TEAMS

**H2 :** Teams

Choose your team structure. Sequential, collaborative, or manager-led — each topology defines how agents interact, pass information, and produce results together.

**Example structures:**
- **Sequential** — Agents hand off in a chain. A → B → C.
- **Group Chat** — A manager agent coordinates the team dynamically.
- **Concurrent** — Multiple agents work in parallel, results merged at the end.

**Finance team example:**
Research Agent → Analysis Agent → Report Agent → your inbox.

## AGENTIC + DETERMINISTIC

**H2 :** Not everything needs to think.

Some steps in your process need intelligence — research, analyse, decide. Others need precision — send, log, publish, trigger. Agentivity handles both in the same flow.

Drop an agentic team where you need judgment. Add a deterministic step where you need reliability.

*(Diagramme SVG — exemple onboarding employé)*
